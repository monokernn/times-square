# Ночной Таймс-сквер

Интерактивная сцена на Three.js. Маршрут начинается на красных ступенях TKTS, лицом к One Times Square. Масштаб площади и взаимное расположение ориентиров приближены по фотографиям. Экраны сочетают театральные афиши разных лет и созданную для сцены рекламу.

## Запуск

В папке с `index.html` выполните `python -m http.server 8080` и откройте [локальную сцену](http://localhost:8080/). Браузеру нужен WebGL 2. Three.js, модели и изображения входят в проект.

Для Vercel поместите содержимое этой папки в репозиторий и импортируйте его с **Framework Preset → Other**. Если репозиторий содержит несколько проектов, выберите папку сцены в **Root Directory**. Оставьте **Build Command** пустым. Выходная директория — корень проекта. [Документация Vercel](https://vercel.com/docs/builds/configure-a-build)

## Управление

| Действие | Управление |
| --- | --- |
| Идти и ускоряться | WASD, удерживать Shift для быстрого шага |
| Смотреть по сторонам | Один раз кликнуть по сцене и двигать мышью. Вместо курсора появится едва заметная точка в центре. Esc возвращает курсор |
| Двигаться с клавиатуры | Стрелки вверх и вниз для движения, влево и вправо для поворота |
| Идти на телефоне | Потянуть палец в левой части экрана. Правая часть управляет взглядом |
| Пролёт и возврат к прогулке | F или иконка стрелки |
| Записать демонстрацию | R или круглая иконка запускает запись с начала маршрута. Через 46 секунд браузер скачивает файл. Повторное нажатие сохраняет текущий фрагмент |
| Полный экран | Enter или угловая иконка |

Запись захватывает холст с городом. Кнопки и курсор находятся вне кадра. Разрешение соответствует рендеру окна в момент старта. Формат — MP4 при поддержке соответствующего кодека или WebM. Запись идёт в реальном времени, поэтому её частота кадров зависит от устройства. Переключение вкладки завершает и сохраняет начатый фрагмент.

## Материалы и устройство сцены

- Положение пешеходных участков и характер мощения сверены с проектом реконструкции. [Snøhetta](https://www.snohetta.com/projects/times-square)
- Красная лестница и павильон собраны по фотографиям Duffy Square. [Perkins Eastman](https://www.perkinseastman.com/projects/tkts-booth-and-the-redevelopment-of-father-duffy-square/)
- Люди подготовлены из моделей Innerscene / MakeHuman по лицензии CC0. В комплекте несколько внешностей, анимации и три уровня детализации. Матрицы костей запечены в текстуры, экземпляры анимируются на GPU. [Коллекция](https://www.innerscene.com/tools/library) · [Пример модели и условия использования](https://www.innerscene.com/tools/library/3d-parts/relaxed-walk-sam-3d-person-animated-732f1206)
- Такси, седаны и SUV подготовлены из моделей Innerscene по лицензии CC0. [Такси](https://www.innerscene.com/tools/library/3d-parts/generic-city-taxi-with-taxi-roof-sign-394afe2b) · [Седан](https://www.innerscene.com/tools/library/3d-parts/sedan-car-42109739) · [SUV](https://www.innerscene.com/tools/library/3d-parts/suv-dc972cab)
- Часть рекламных текстур получена из фотографий, предоставленных для проекта. Витрины, часть фасадов и рекламных изображений созданы с помощью ImageGen. Остальная геометрия и материалы подготовлены для этой сцены. Лицензия Three.js лежит в `vendor/THREE-LICENSE.txt`.
